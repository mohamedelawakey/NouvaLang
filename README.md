# NouvaLang 🚀

NouvaLang is a modern, open-source programming language designed to bring the best of both worlds: the raw performance of **C** and the elegant, easy-to-read syntax of **Python**. Built from scratch in Rust, our ultimate vision is to create a highly performant language with first-class support for Artificial Intelligence and Machine Learning libraries natively in the future.

## ✨ Features
- **Fast Execution:** Designed to be compiled and perform at the speed of C.
- **Developer-Friendly Syntax:** Clean, Python-like syntax that is easy to write and read.
- **Future AI Integration:** Planned native support for AI and data science libraries.
- **Built with Rust:** Leveraging Rust's safety and performance for the compiler toolchain.

## 🚧 Current Status
We are currently actively developing **v0.1 (MVP)** of the language.

- [x] **Phase 1: Lexical Analysis (Lexer)**
  - [x] Tokenization for all keywords, types, and literals
  - [x] Multi-character operators handling (`==`, `->`)
  - [x] String and Boolean literals support
  - [x] Single-line and multi-line comments
- [ ] **Phase 2: Parsing (Parser) - *Up Next***
  - [ ] Abstract Syntax Tree (AST) Generation
  - [ ] Parsing Variables and Types (`let`, `int`, `float`, `bool`, `string`)
  - [ ] Parsing Functions (`fun`)
  - [ ] Parsing Control Flow (`if` / `else`)
  - [ ] Parsing Loops (`while`)
- [ ] **Phase 3: Evaluation/Compilation - *Pending***
  - [ ] Code execution
  - [ ] Built-in functions (e.g., `print`)
